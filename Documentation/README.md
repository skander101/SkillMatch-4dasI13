- Les livrables sont rédigés en français.

- Les sources Mermaid seront ajoutées dans `Diagrams/` lorsqu'elles seront disponibles.
- Le document technique reprend et détaille tout le contenu de la présentation.
- Pour les nouveaux fichiers, utiliser des noms en minuscules avec des tirets.
- Chaque membre vérifie que sa partie est présente avant la soumission.
